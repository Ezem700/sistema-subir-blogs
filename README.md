# Sistema Blogs Django

Plataforma web donde usuarios registrados pueden publicar, comentar y dar like a blogs, con control de moderación para el admin.

## Estructura del proyecto

```
sistema-blogs-django/
├── 00_REFERENCIAS/           # Análisis y requisitos
├── 01_PLAN_MAESTRO/          # Visión y decisiones estratégicas
├── 02_CASOS_DE_USO/          # Requisitos funcionales
├── 03_ARQUITECTURA/          # Diseño arquitectónico
├── 04_MODELO_DATOS/          # Dominio y persistencia
├── 05_AGENTES_IA/            # Metodología de agentes
├── 06_INTERFAZ_USUARIO/      # Diseño de UI/UX
├── 07_IMPLEMENTACION/        # Guías técnicas
├── 08_CODIGO_FUENTE/         # Código fuente
└── README.md
```
